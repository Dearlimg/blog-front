Security Platform — Agent Infrastructure

Key Responsibilities

  • Multi-node Concurrent Task Orchestration & Scheduling (Core): designed a "create-order / dispatch-decoupled" architecture with full task-state persistence for resume-from-checkpoint after process restarts; dispatch via absolute start timestamps achieves synchronized second-level concurrency across machines, breaking the single-machine throughput bottleneck to support 500K-level HTTP traffic evaluation; 650+ end-to-end unit tests covering routing, concurrent dispatch, failure determination, and other edge cases.
  • Control-Plane / Data-Plane Split-Brain Handling: for the split-brain scenario where "dispatch requests time out but the node has actually accepted the order", used idempotent progress probing to confirm the real acceptance state, eliminating permanent loss of evaluation data caused by misjudged FAILED status.
  • Proactive Health-Check Liveness Detection: replaced passive node reporting with platform-side polling (pull) for liveness; a three-tier mechanism of consecutive-failure determination + soft-revival probing + hard-timeout fallback keeps liveness stable even when attack tools saturate node resources.
  • Distributed Time-Series Metrics Collection (False-Positive Rate Measurement): second-level bucketing + attack-window aggregation time-series scheme; under sustained probing across 10 nodes, precisely slices any attack window from the continuous data stream; unified "total-sum" false-positive-rate metric avoids the statistical distortion of averaging ratios across nodes.
  • AI Engineering — Fix Closed-Loop & Multi-Agent Collaboration: wrapped a weakness-fix progress reporting tool over the MCP protocol for coding agents to call, building an "agent auto-report → visualization dashboard" fix closed-loop; explored multi-agent collaboration workflows, validating agents autonomously completing the end-to-end development chain of "branch → develop → merge".
